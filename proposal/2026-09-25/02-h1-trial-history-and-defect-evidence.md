## 2. Trial-4 causal chain and corrective test

At [`zcode_hook_main.cpp`](https://github.com/JasonHuang3D/qiven-runtime/blob/7b3ce515774de8f146aefc066ffbf0e69e2e33a4/apps/zcode_hook_main.cpp) the hook assigns 9750 ms for `session_start` and 4750 ms for other events. [`zcode_hook.cpp`](https://github.com/JasonHuang3D/qiven-runtime/blob/7b3ce515774de8f146aefc066ffbf0e69e2e33a4/src/adapter/zcode_hook.cpp) copies that value into both hello and event. [`protocol.cpp`](https://github.com/JasonHuang3D/qiven-runtime/blob/7b3ce515774de8f146aefc066ffbf0e69e2e33a4/src/ipc/protocol.cpp) permits 10000 only for `HookEvent + session_start` and caps hello at 5000. [`runtime_host.cpp`](https://github.com/JasonHuang3D/qiven-runtime/blob/7b3ce515774de8f146aefc066ffbf0e69e2e33a4/src/host/runtime_host.cpp) checks session registration before path classification; the outside-scope probe therefore cannot return `not_governed` after registration failed.

The preflight exercised a 4750 ms tool probe only and counted *any* host verdict as a round trip. A discriminating regression first sends a high-budget SessionStart through **hello then event on one real connection**, proves session registration in the journal, then asserts both governed denial and outside-scope allowance in that same session. Add a bound for the **whole hook transaction**, because passing separate frame ceilings can still overrun the harness hook timeout. A named integer wrapper without a shared frame policy would pass neither criterion.

The proposed typed path value must not silently replace that security requirement.

## 4. Historical and quantitative claims

[ADR-0007](https://github.com/JasonHuang3D/qiven-context/blob/c73b2288bb1dabfa87a5c222eeab0d7bae6ac2ff/decisions/ADR-0007.md) was superseded by [ADR-0024](https://github.com/JasonHuang3D/qiven-context/blob/c73b2288bb1dabfa87a5c222eeab0d7bae6ac2ff/decisions/ADR-0024.md) on 2026-09-15. The latter explicitly prefers correct lower ownership on the first serious implementation even with one consumer, while rejecting speculative Foundation completion. [The engineering philosophy](https://github.com/JasonHuang3D/qiven-context/blob/c73b2288bb1dabfa87a5c222eeab0d7bae6ac2ff/collaboration/software-engineering-philosophy.md) already says "we can refactor later" is not a design argument. The observed recurrences show an **enforcement/acceptance gap under existing law**, not that the law still prescribes local-first work.

The owner attributes substantial historical time/token cost to local-first deferrals. The inspected public audits establish specific incidents and repeated owner involvement; they do **not** measure a billion-token causal total, a one-day cost for each trial, or that every path-form drift caused a production failure. Those numbers remain owner assessment, not measured acceptance data. The router env-prefix classifier and the SQLite reserved-word defect concern separate parsing/schema contracts; do not count them as path or deadline failures without a distinct causal argument. The local harness mock-provider PoC and disposable trial-4 reproduction are described in the canonical audit/checkpoint but were not independently retrieved or executed in this GitHub-only review; the acceptance program must pin their artifacts before claiming reuse.

## 5. Supported conclusion

A single central contract for the concrete deadline transaction, distinct lexical and OS-backed path responsibilities, tests that cross actual client/host/harness boundaries, and an honest Desktop carrier claim follow from this record. The incident history does not establish that one universal typed-identity class, a 100-case numerical target, or a CLI-only green run is sufficient on its own.
